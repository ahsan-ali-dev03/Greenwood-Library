# 📚 Greenwood Library

A modern, clean, and fully responsive library website built using **HTML5** and **Tailwind CSS**.

The Greenwood Library website provides a simple and user-friendly interface for exploring library sections, viewing the gallery, checking membership plans, discovering upcoming events, and finding contact information.

- 📱 Fully responsive design
- 💻 Desktop and mobile layouts
